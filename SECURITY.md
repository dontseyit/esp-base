# Security

## Reporting

Report a vulnerability privately through GitHub: **Security** tab, **Report a vulnerability**. Please do not open a public issue for it. You should hear back within a week.

## Scope

esp-base serves HTTP without TLS and is meant for a trusted LAN. The protections it does provide, and what remains the project's job (passwords before shipping, flash encryption, Secure Boot), are listed in [docs/wiki/Security.md](docs/wiki/Security.md). Reports about those documented limits are out of scope; reports about a protection not working as documented are in scope.

Only the latest release receives fixes.
